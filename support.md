# PinaCode support
PinaCode lets you continue a coding session from your iPhone or iPad. [Privacy policy](privacy.md).

1. Install [PinaCode](https://github.com/zjywill/PinaCode) on your computer and configure the coding provider there.
2. Start the host in LAN mode with `pinacode up --lan`. Run `pinacode pair` and open the pairing link on your mobile device.
3. Keep the host awake. If pairing fails, check that the phone can reach the host and that Local Network is allowed in iOS Settings. Generate a new pairing link if yours expired.
4. Open a project and a thread to read the conversation, inspect changes, or send a follow-up.

**Beta feedback:** Use Send Beta Feedback in TestFlight or email zjywill@gmail.com. Include your iOS version, app build and steps to reproduce. Never send a pairing link, access token or private code.
