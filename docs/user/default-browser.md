# Use PinaCode as your default browser

On macOS, you can set the PinaCode desktop app as your default web browser so links from other apps and local HTML files open directly in PinaCode.

## Enable

Choose **PinaCode** in **System Settings → Desktop & Dock → Default web browser** (switch back there anytime).

## How links open

- If the active thread has its browser panel open, the link opens as a new tab there; otherwise PinaCode opens a new no-project thread with the browser panel maximized so you can ask an agent about the page right away.
- Pull request links for connected projects open in the PR view (when **Open pull requests in PinaCode** is enabled).
- [Prompt links](./prompt-links.md) to `app.t3.codes` open as a draft.
